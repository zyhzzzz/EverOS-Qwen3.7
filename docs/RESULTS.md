# 结果、异常与解释

## 结果口径

分母固定：训练154题、每组测试65题。Judge 采用固定官方语义匹配提示词；不是仅字符串相等。表中所有题的最终 verifier 方法均为 `llm_judge`。接口拦截、空最终答案仍计入分母，不从样本中删除。

| 运行 | Train | Baseline | EverOS | Skill | 测试增益 |
| --- | --- | --- | --- | --- | --- |
| Run 1 | 77/154 = 50.00% | 23/65 = 35.38% | 29/65 = 44.62% | 17 | 6题 / 9.23个百分点 |
| Run 2 | 78/154 = 50.65% | 22/65 = 33.85% | 29/65 = 44.62% | 20 | 7题 / 10.77个百分点 |

两次均值：baseline 34.62%，EverOS 44.62%，平均差10.00个百分点。这里“个百分点”不是相对提升百分比。重复使用同一65题，不能把两次130个观察当作130道独立题。

## 逐题配对

| 同次比较 | 两组都对 | EverOS 独有正确 | Baseline 独有正确 | 两组都错 |
| --- | --- | --- | --- | --- |
| Run 1 | 21 | 8 | 2 | 34 |
| Run 2 | 18 | 11 | 4 | 32 |

两次之间，baseline 对错变化13题，EverOS 对错变化8题。因此“EverOS 两次都是29题正确”不能解释为完全相同的回答或稳定解决了相同29题。变动 ID 在 `evidence/summary.json`。

这是两次端到端重复，同时包含训练轨迹、记忆生成、检索、作答和 judge 的随机性。不是固定技能库、仅重复评测的随机性消融。

## 答案审查范围

- 两次全部568条 train/test记录的最终提交文本与规定的最后正常公开回答选择一致；没有发现文本提取不一致。空回答同样参与该结构检查。
- Run 1 已读错题评分与对题的答案对照，并针对异常项核查原文；这不是每题所有背景事实均独立查证。
- Run 1 存在姓名顺序、历史机构名称等未决语义争议（如410、1072），没有因此手工加分。
- Run 2 完成了结构、评分方法、接口错误和逐题变化检查，尚未逐题独立重新判断别名等语义问题。当前成绩为保留的 judge 结果，不冒充全量独立复判。
- 不公开题目/答案实例，因为 BrowseComp-Plus 有避免明文在线传播的要求。授权审查者可在受控环境按 ID 查阅私有冻结记录。

## 与排行榜的关系

不能将本实验数字直接用来验证或否定历史 Qwen3.5-397B 的 +20.0个百分点：模型、API提供商、答案提取、本地模型服务及未完全冻结的环境均有差异。当前榜单的 Anchor Skill 也不是本次 EverOS 方法。合理结论是：在本材料记录的 Qwen3.7-Flash 配置与官方 split 上，两次单次实验都观察到正向差值，外推范围有限。
